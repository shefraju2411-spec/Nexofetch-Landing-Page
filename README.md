# Nexofetch Landing Page

Google Ads landing page for Nexofetch — China sourcing / purchasing office for growing European brands.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Vercel, Netlify, or Cloudflare Pages, then point a subdomain such as `lp.nexofetch.com`.
